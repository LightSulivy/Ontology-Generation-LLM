02 · Solution

Deux modes de génération, des définitions pour mesurer

Génération indépendante

Une CQ + sa story → un module OWL. Toutes les ontologies du jeu, GPT-4 seul.

Génération incrémentale

Toutes les CQ d’une story → une ontologie. 3 stories × 15 CQ, 3 LLM.

Module minimal

L’ontologie de référence réduite aux éléments utiles à une CQ : le gold standard.

Élément superflu

Classe ou propriété nommée absente de toutes les requêtes SPARQL de validation.

Problème mineur

Il ne manque qu’une seule propriété pour que la CQ soit modélisée.

8 · Sections 3 et 4.3 · GPT-4-1106 (temp. 0), o1-preview et Llama-3.1-405B (paramètres par défaut)

Orateur A. Les techniques sont testées dans deux modes. En génération indépendante, chaque CQ produit son propre module ; c’est fait sur tout le jeu de données, mais avec GPT-4 seulement. En génération incrémentale, toutes les CQ d’une story produisent une seule ontologie ; c’est fait avec trois LLM (GPT-4, o1-preview, Llama 3.1 405B), mais seulement sur les trois stories du cours de 2008-2009 : hôpital, musique, théâtre, 15 CQ chacune. Les auteurs définissent trois notions qui servent ensuite de métriques : le module minimal (la référence), l’élément superflu (présent dans l’ontologie mais inutile pour les requêtes de test) et le problème mineur (une seule propriété manque). Je passe la parole pour le positionnement.
